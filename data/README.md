# Привет! Вот датасет v0.1 для мутаций.

## Файл: data/clean/v0.1_enriched.jsonl (50 строк).
## Что внутри:
Каждая строка — это JSON с задачей.

task_id — уникальный ID (например, hp_000). Используй его для связи мутации с оригиналом.

input — текст задачи, который ты будешь мутировать.

expected_output — правильный ответ (нужен, чтобы проверять, не изменился ли смысл).

task_type — тип задачи (multi_hop или comparison).
## Что от тебя нужно:
Сгенерируй мутации и сохрани их в data/mutated/mutations.jsonl в таком формате:
{
  "mutation_id": "m_001", 
  "task_id": "hp_000", 
  "mutation_type": "paraphrase", 
  "intensity": "easy", 
  "mutated_input": "Текст измененной задачи..."
}
